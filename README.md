## Description

Personal Task Manager is a simple Laravel web application that allows users to manage their tasks. Users can add, view, edit, delete, and update the status of their tasks.

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Task Status
- Set Due Date

## Technologies Used

- Laravel
- PHP
- MySQL
- Blade
- HTML
